Bundled fonts use `@fontsource-variable/<directory>` packages. Each stylesheet
records its package version. Licenses are included in each family directory.

The `*-legacy-*.woff2` supplements preserve characters in the legacy TTF fonts
but absent from Fontsource.
They were created with FontTools 4.63.0 from the TTF files at commit
`9977750fe34b32d00ce3167cf36b80f942ba673f`.
